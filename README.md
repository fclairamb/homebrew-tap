# homebrew-tap

Homebrew tap for [SolidPing](https://solidping.io), self-hostable uptime monitoring.

```bash
brew install fclairamb/tap/solidping
solidping serve
```

The formula installs the release binary from
[fclairamb/solidping](https://github.com/fclairamb/solidping/releases) (macOS and Linux,
arm64 and amd64). A daily workflow bumps it to the latest release.
